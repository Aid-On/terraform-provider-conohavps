# conohavps_network (Resource)

Manages a local network (VLAN). The network takes no arguments: ConoHa names it. Up to 10 local networks can be created per ConoHa account. Add a `conohavps_subnet` to it before creating ports. A network cannot be deleted while subnets or ports remain on it.

## Example Usage

```terraform
# A local network takes no arguments; ConoHa names it.
resource "conohavps_network" "local" {}
```

## Schema

### Read-Only

- `id` (String) The ID of the network.
- `mtu` (Number) The MTU of the network.
- `name` (String) The name ConoHa gives the network, such as `local-gnct24510032-1`.
- `status` (String) The status of the network, such as `ACTIVE`.

## Import

A network can be imported using its `id` .

For example:

```shell
$ terraform import conohavps_network.local {{network_id}}
```
