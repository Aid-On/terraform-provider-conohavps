# conohavps_securitygroup_rule (Resource)

Manages security group rule resource.

~> To expose all ports (1-65535), set `port_range_min` and `port_range_max` to `0`.

## Example Usage

```terraform
resource "conohavps_securitygroup" "group_1" {
  name = "tf-example-security-group-1"
}

resource "conohavps_securitygroup" "group_2" {
  name = "tf-example-security-group-2"
}

# Expose all ports (1-65535)
resource "conohavps_securitygroup_rule" "rule_1" {
  securitygroup_id = resource.conohavps_securitygroup.group_1.id
  direction        = "ingress"
  ethertype        = "IPv4"
  protocol         = "tcp"
  port_range_min   = 0
  port_range_max   = 0
}

# Expose a specific port range
resource "conohavps_securitygroup_rule" "rule_2" {
  securitygroup_id = resource.conohavps_securitygroup.group_2.id
  direction        = "ingress"
  ethertype        = "IPv4"
  protocol         = "tcp"
  port_range_min   = 80
  port_range_max   = 8080
}
```

## Schema

### Required

- `direction` (String) The direction of the security group rule. Valid values are `egress` or `ingress` . Changing this value will create a new security group rule.
- `ethertype` (String) The layer 3 protocol type. Valid values are `IPv4` or `IPv6` . Changing this value will create a new security group rule.
- `securitygroup_id` (String) The security group ID to which the security group rule belongs. Changing this value will create a new security group rule.

### Optional

- `port_range_max` (Number) The higher part of the allowed port range. If omitted, accepts any port or any ICMP type. When the protocol is `tcp` or `udp` , valid value needs to be between `1` and `65535` . When the protocol is `icmp`, valid value needs to be between `0` and `255` . Changing this value will create a new security group rule.
- `port_range_min` (Number) The lower part of the allowed port range. If omitted, accepts any port or any ICMP type. When the protocol is `tcp` or `udp` , valid value needs to be between `1` and `65535` . When the protocol is `icmp`, valid value needs to be between `0` and `255` . Changing this value will create a new security group rule.
- `protocol` (String) The layer 4 protocol type. Valid values are `tcp` or `udp` or `icmp` . If omitted, accepts any protocol. When specifying this option, a port range needs to be specified. Changing this value will create a new security group rule.
- `remote_group_id` (String) The ID of remote group. The value needs to be the security group ID. This option is mutually exclusive with `remote_ip_prefix` . Changing this value will create a new security group rule.
- `remote_ip_prefix` (String) The remote CIDR. The value needs to be a valid CIDR. This option is mutually exclusive with `remote_group_id` . Changing this value will create a new security group rule.

### Read-Only

- `id` (String) The ID of the security group rule.
