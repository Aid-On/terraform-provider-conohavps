# conohavps_credential (Resource)

Manages an EC2-style credential (an access key and a secret key) of an API user, used by S3-compatible clients of the object storage. An API user can have at most 3 credentials. Credentials cannot be updated; changing any argument creates a new credential.

## Example Usage

```terraform
# An access key and secret key for S3-compatible clients of the object storage
resource "conohavps_credential" "backup" {
  user_id = var.api_user_id # the API user that owns the credential
}

variable "api_user_id" {
  type = string
}

output "access_key" {
  value = conohavps_credential.backup.access
}

output "secret_key" {
  value     = conohavps_credential.backup.secret
  sensitive = true
}
```

## Schema

### Required

- `user_id` (String) The ID of the API user that owns the credential. Changing this value will force the credential to be recreated.

### Optional

- `tenant_id` (String) The tenant ID the credential is scoped to. Defaults to the provider's `tenant_id`. Changing this value will force the credential to be recreated.

### Read-Only

- `access` (String) The access key.
- `id` (String) The ID of the credential, which is the access key.
- `secret` (String, Sensitive) The secret key.

Credentials can be imported using `<user_id>/<access>` .
