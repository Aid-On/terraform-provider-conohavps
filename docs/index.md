# ConoHa VPS Provider

The ConoHa VPS provider is used to interact with the resources supported by the [ConoHa VPS](https://vps.conoha.jp/) via the [ConoHa VPS public APIs](https://doc.conoha.jp/reference/api-vps3/).

!> The ConoHa VPS provider is only supported ConoHa VPS(Ver.3.0). Cannot be used for ConoHa VPS(Ver.2.0).

-> Currently in beta, data sources are not provided. Please obtain the parameters required for resource creation from the [ConoHa VPS public APIs](https://doc.conoha.jp/reference/api-vps3/).

## Example Usage

```terraform
terraform {
  required_providers {
    conohavps = {
      source = "gmo-internet/conohavps"
    }
  }
}

# Configure the ConoHa VPS provider
provider "conohavps" {
  identity_endpoint = "Your identity endpoint"
  password          = "Your password"
  region            = "Your region"
  tenant_id         = "Your tenant ID"
  user_id           = "Your user ID"
}
```

## Configuration

-> Please create a public API user in advance. See the [create API user documentation](https://doc.conoha.jp/reference/api-vps3/api-cp-vps3/cp-create_api_user-v3/) .

!> Please exercise extreme caution when managing the provider configuration that contain authentication information.

The ConoHa VPS provider accepts two configuration sources.
If both are provided, the environment variable is used.

- Parameters in the provider configuration
- Environment variables

## Schema

### Optional

- `identity_endpoint` (String) The identity endpoint of ConoHa VPS Public API. The default value is `https://identity.c3j1.conoha.io/v3`. Can also be set with the `CONOHAVPS_IDENTITY_ENDPOINT` environment variable.
- `password` (String, Sensitive) The password of the ConoHa VPS Public API. Can also be set with the `CONOHAVPS_PASSWORD` environment variable.
- `region` (String) The region of ConoHa VPS. The default value is `c3j1`. Can also be set with the `CONOHAVPS_REGION` environment variable.
- `tenant_id` (String) The Tenant ID of the ConoHa VPS Public API. Can also be set with the `CONOHAVPS_TENANT_ID` environment variable.
- `user_id` (String) The user ID of the ConoHa VPS Public API. Can also be set with the `CONOHAVPS_USER_ID` environment variable.
