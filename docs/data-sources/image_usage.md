# conohavps_image_usage (Data Source)

Reads how much of the image save capacity the account's images use. `conohavps_image_quota` cannot be set below this usage.

## Example Usage

```terraform
# How much of the image save capacity the saved images use
data "conohavps_image_usage" "current" {}

output "image_usage_gb" {
  value = data.conohavps_image_usage.current.size_bytes / 1073741824
}
```
