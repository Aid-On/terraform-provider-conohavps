# conohavps_qos_policy (Data Source)

Looks up a QoS policy by name, such as `global-i_300000-o_300000` (300 Mbps, a paid option) or `global-i_100000-o_100000` (the 100 Mbps default), or by ID. Use its `id` as `qos_policy_id` of `conohavps_port` or `conohavps_additional_ip`.

## Example Usage

```terraform
# Look up the 300 Mbps policy (a paid option) by its name
data "conohavps_qos_policy" "fast" {
  name = "global-i_300000-o_300000"
}

resource "conohavps_additional_ip" "fast" {
  ip_count      = 1
  qos_policy_id = data.conohavps_qos_policy.fast.id
}
```

- `shared` (Boolean) Whether the QoS policy is shared.
- `tags` (List of String) The tags of the QoS policy, such as `billing_flag=true` for a paid policy.
