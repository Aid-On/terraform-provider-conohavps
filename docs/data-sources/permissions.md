# conohavps_permissions (Data Source)

Lists the permissions that can be granted by a `conohavps_role`. Each permission allows one API operation, such as `get-server-list`. There are no permissions for the role APIs, the Object Storage API and the DNS API.

## Example Usage

```terraform
# List the permissions that can be granted by a role
data "conohavps_permissions" "all" {}

# Grant every read-only (get-*) permission of the servers
resource "conohavps_role" "server_viewer" {
  name        = "server-viewer"
  permissions = [for name in data.conohavps_permissions.all.names : name if startswith(name, "get-server")]
}
```
