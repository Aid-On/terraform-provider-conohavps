# conohavps_dns_domain (Data Source)

Looks up a domain registered in ConoHa DNS by name. Use its `id` as `domain_id` of `conohavps_dns_record`.

## Example Usage

```terraform
# Look up a domain already registered in ConoHa DNS by its name
data "conohavps_dns_domain" "example" {
  name = "example.com."
}

resource "conohavps_dns_record" "www" {
  domain_id = data.conohavps_dns_domain.example.id
  name      = "www.example.com."
  type      = "A"
  data      = "192.0.2.10"
}
```
